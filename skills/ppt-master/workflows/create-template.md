# Create Template Workflow

**When to use**: Standalone layout template creation.

## Prerequisites

- Design spec or visual concept for the template.

## Steps

1. Read `references/template-designer.md` for template creation rules.
2. Read `templates/layouts/layouts_index.json` for existing templates.
3. Create a new template directory under `templates/layouts/<template-id>/`.
4. Create SVG template files following the layout conventions.
5. Update `templates/layouts/layouts_index.json` to include the new template.
6. Test with a sample project.
