# Topic Research Workflow

**When to use**: User provides only a topic or requirements without any file or substantive description.

## Steps

1. Use web search to find relevant materials on the topic.
2. Gather 3-6 high-quality sources (articles, reports, papers).
3. Use `ppt-master_convert-source` with `type: "web"` for each URL, or extract key information manually.
4. Compile the research into a consolidated Markdown document.
5. Return to Step 1 of the main SKILL.md workflow with the compiled source as input.

## Quality Gates

- Sources must be credible and relevant to the presentation topic.
- Extracted content must cover key angles of the topic.
- The compiled document should be 500-3000 words depending on presentation depth.
